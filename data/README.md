# Data Directory

## Structure

- **raw/** - Original, immutable data files
  - Contains raw data from Privacy Rights Clearinghouse, CRSP, and Compustat
  - Do not modify files in this directory

- **processed/** - Cleaned and transformed data files
  - Contains merged datasets, feature-engineered variables
  - Intermediate outputs used in analysis

## Data Sources

- **Privacy Rights Clearinghouse (PRC)**: Data breach records (1,054 breaches, 2006-2025)
- **CRSP**: Daily stock returns and market data
- **Compustat**: Annual financial statements for publicly-traded firms
